# Stil-Profil aus dem Template ableiten

Alle Vorgaben werden dem Template entnommen (inkl. Sprache). Das Profil vor dem Befüllen
als Kurzprofil (max. ~15 Zeilen) zeigen und bestätigen lassen.

| Dimension | Was erfassen |
|---|---|
| **Sprache** | Sprache, Variante (z. B. Schweizer Rechtschreibung: kein ß, «»-Anführungszeichen), Fachvokabular |
| **Anrede/Perspektive** | Sie/du/neutral, Wir-/Ich-/unpersönlich |
| **Tonalität** | formell/sachlich/werblich, Verbindlichkeit (muss/soll/kann) |
| **Satzbau** | typische Satzlänge, Nominalstil vs. Verbalstil, Zeitform |
| **Gliederung** | Heading-Ebenen, Nummerierung (`1.`, `2.1`), Pflichtabschnitte, Reihenfolge |
| **Flow** | Aufbau pro Abschnitt (z. B. Kontext → Anforderung → Konsequenz), Absatzlänge |
| **Listen/Tabellen** | Bullets vs. Nummerierung, Fettdruck-Lead-in (`**Begriff** – Text`), Tabellenspalten, Metadaten-Block |
| **Formate** | Datum, Zahlen (`3'000`), Währung, Einheiten, Abkürzungen |
| **Platzhalter** | Konvention (`[…]`, `{{…}}`, `XXXX`), Beispielwerte, Hinweis-/Anleitungstexte (beim Befüllen entfernen) |
| **Besonderheiten** | Diagramme (ASCII/Mermaid), Codeblöcke, Kopf-/Fusszeile, feste Formulierungen, die unverändert bleiben müssen |

## Hinweise

- Feste, im Template vorgegebene Textbausteine (Rechtliches, Standardsätze) **unverändert** lassen.
- Mehrere Beispiele im Template (z. B. drei Bullet-Beispiele) sind Stil-Muster, keine Pflichtanzahl –
  Anzahl richtet sich nach der Quellenlage.
- Bei `.docx` zusätzlich Formatvorlagen-Namen (`Heading 1`, `List Bullet` …) und Tabellenstile notieren;
  Inhalt immer in den vorhandenen Formatvorlagen ablegen.
