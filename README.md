# bender
Your sticky project assistant :).

## Installation

Im Projektordner (PowerShell):

```powershell
irm https://raw.githubusercontent.com/bfabricius/bender/main/install.ps1 | iex
./bootstrap-wizard.ps1
```

Das Toolkit wird als reine Dateien installiert (ohne `.git`), damit es das Git-Repo des
Projekts nicht stoert. Details: [.toolkit/README.md](.toolkit/README.md).
